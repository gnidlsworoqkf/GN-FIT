스펙트럼 바 위치 계산
Q1~Q60 중 A 응답 개수 / 전체 응답 개수 × 100 = A비율(%)
마커 위치 = 100 - A비율

예시: A를 60%로 선택했다면 → 마커는 40% 위치 (왼쪽, 절차·안정형 쪽)
④ 리포트 3페이지 — 각각 무엇을 보여주나
PAGE 1 종합 요약
총점 + 상위 % 순위 + 평균 대비 차이
전체 응시자 점수 내림차순 정렬 → 퍼센타일 표시. 전체 평균 대비 ±점수도 함께 표시.
물결 실루엣 + 6각형 레이더 차트 🔄
왼쪽: 총점만큼 물이 차오르는 실루엣 + 상위% 텍스트. 오른쪽: 6각형에 역량명과 점수 라벨 직접 표기. 최고점=빨강, 최저점=주황.
종합 의견 멘트 🔄 개인화
총점 구간 4가지 × 강점/약점 역량 조합 → 지원자마다 다른 멘트 생성. 유형명도 멘트에 포함.
PART1 vs PART2 갭 인디케이터
6개 역량 각각의 가치관(P1)과 실제행동(P2) 수치를 두 줄 바로 표시. 갭 20점 이상 시 빨간 바 + ⚠ 경고.
우수/보완 역량 카드 🔄
상위 2개 강점, 하위 2개 약점. 점수만이 아닌 역량별 한 줄 분석 코멘트 자동 표시.
PAGE 2 심층 분석 + 면접 가이드
역량별 응답 패턴 테이블
6개 역량 × A/B 비율 계산 → 그라디언트 바로 시각화. 갭 20점↑이면 빨간 경고 문구 자동 삽입.
심층 분석 — 6개 역량 전체 표시 🔄
Q9·Q12·Q25·Q34·Q45·Q56 응답 체크. 이상 없으면 ✔ 표시, 경고는 ⚠, 위험은 🚨. 6개 역량 전부 2열 그리드로 표시해 페이지 빈 느낌 없앰.
면접관 체크리스트 🔄
기존: 약점 역량 질문만. 변경: 강점 2개(강점 확인용) + 약점 2개(심층 검증용) 좌우 2열로 분리. 각 역량당 경험 검증 + 상황 압박 2문항.
패턴 분석 설명 자동 생성
A/B 우세 방향에 따라 다른 분석 코멘트 자동 생성. 예: A형 60% → "절차 준수 성향 60% — 지시 기다리는 경향" 등.
PAGE 3 행동 성향 + 신뢰도 + 채용 추천
행동 성향 유형 + 스펙트럼 바
4가지 유형 중 하나 + 설명 + 장단점. 하단에 절차·안정형 ↔ 주도·혁신형 그라디언트 바에 마커 위치 표시.
Paradox 섹션 제거 🔄
기존 역설 경고 섹션 삭제. PAGE 1 갭 인디케이터, PAGE 2 심층 분석과 중복이어서 통합 제거.
신뢰도 — 역량별 일치율 상세 🔄
기존: 점수 숫자만. 변경: 왼쪽 점수 박스 + 오른쪽 역량별 거울 문항 일치율 막대. Fake-Good 배지도 신뢰도 섹션으로 통합.
